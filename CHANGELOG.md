# Изменения LDTF

Формат: для каждой версии — что нового для пользователя. Раздел версии целиком становится описанием релиза на GitHub
и показывается в LDTF перед обновлением.

## 1.4.0 — 2026-10-06

- **LDTF.exe.** Релиз для Windows запускается файлом `LDTF.exe` с иконкой LDTF вместо `.cmd`; автозапуск и ярлыки
  переходят на него сами. С 1.3 на 1.4 обновитесь один раз вручную: распакуйте архив поверх старой папки.
- **Обновление из настроек.** Раз в день LDTF проверяет, вышла ли новая версия (можно выключить), показывает, что
  нового, и ставит её по кнопке: скачивает, сверяет контрольную сумму, перезапускается, а если новая версия не
  запустилась — возвращает прежнюю.
- **Docker.** Образ `ghcr.io/gwynerva/ldtf` (amd64, arm64) и `compose.yaml` для сервера или NAS: веб-интерфейс с паролем,
  архивы в томе, обновление командой `docker compose pull`.
- **ИИ-агенты (MCP).** Claude, Cursor и другие клиенты ищут по архивам и читают посты, ветки комментариев, историю
  правок и статистику — только чтение. Готовые команды — в «Настройках приложения → ИИ-агенты».
- **История версий.** Правки постов и комментариев сохраняются: у поста — «изменён · N версий» со сравнением версий,
  у комментария — «история». Удаления и возвращения на DTF тоже в истории; все изменения архива — на странице
  «Изменения на DTF».
- **Донаты.** Суммы на постах, выделенные донат-комментарии, страница «Донаты» с топом постов и донатеров.
- **Свежая статистика.** Счётчики, реакции и донаты постов обновляются каждой синхронизацией, а не только после
  правки поста.
- **Блоки DTF.** Каталог всех блоков редактора DTF с образцами и настоящими примерами из архивов; в настройках архива —
  проверка постов с блоками, которые LDTF показывает упрощённо. Аудио и посты из Telegram теперь показываются полностью.
- **Дизлайки — один список для всех архивов**, в «Настройках приложения → Реакции».
- Исправления: занятый порт больше не «делится» с другой программой; LDTF другой папки на порту 8765 не принимается за
  уже запущенный; консольный `serve` не трогает автозапуск; `docker stop` даёт синхронизациям сохранить прогресс.

## 1.3.0 — 2026-10-01

- Все настройки сохраняются сами, как только их меняют; старая вкладка браузера больше не может выключить другие
  настройки или автозапуск.
- Автозапуск показывает своё настоящее состояние (в том числе когда LDTF выключен в автозагрузке Windows) и не
  перехватывается другой копией LDTF; изменения настроек и автозапуска пишутся в `app.log`.
- Новые архивы синхронизируются каждый день в 09:00.

## 1.2.0 — 2026-09-29

- Архивы «Только посты»: без комментариев, веток и их медиа; режим выбирается при создании архива и меняется потом
  (с подтверждением и подсчётом освобождаемого места).
- Медиафайлы: все, только из постов или никакие; чего нет в архиве, показывается с DTF или аккуратной заглушкой.
- Сетевые параметры больше не настройки: LDTF подстраивается под DTF сам.
- Уведомления в трее только о важном, понятные статусы и «Совместимость с DTF».
- Исправления: формы, обрезанные меню, очистка медиа, автоматическая пересборка архивов после обновления.

## 1.1.1 — 2026-09-28

- Работает полностью без интернета: медиа чужих комментариев в ветках тоже скачиваются.
- Без сети синхронизация сразу сообщает «нет подключения к интернету».
- Повреждённая `view.sqlite` одного архива больше не ломает остальные страницы.

## 1.1.0 — 2026-09-28

- Первая версия: посты, комментарии со всего сайта с контекстом, медиа, поиск, несколько архивов, трей, расписание,
  защита от удалений.
